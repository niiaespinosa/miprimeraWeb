# Página web simple
## Objetivo
Crear una página web, con el objetivo de comprender la estructura y los lenguajes utilizados en este tipo de infraestructuras  

Más allá de crear una página con fines de aprendizaje, el contenido está enfocado en permitir un acercamiento de los lectores con especies de plantas nativas, creando consiencia sobre su existencia e importancia en el entorno.
